# keelLink for Mac — releases

keelLink shows the Claude Code sessions shared from VSCode (keelLinkd) on your Mac: read along, type, answer
permission requests, upload files, preview what Claude builds.
这里只放 Mac 版的安装包（dmg）和更新说明。

## 安装 / Install

1. 下载最新 release 的 `.dmg`，把 keelLink 拖进「应用程序」。 / Download the latest `.dmg`, drag keelLink into Applications.
2. 在 VSCode 的 keelLink 会话里点 **Share to phone**，⌃⇧⌘4 截二维码到剪贴板，在 keelLink 里按 ⌘V。
   / In VSCode's keelLink session click **Share to phone**, copy a screenshot of the QR code (⌃⇧⌘4), press ⌘V in keelLink.

## 更新 / Update

keelLink 菜单 →「检查更新…」：下载、核对签名和公证后替换并重新打开。 / keelLink menu → 检查更新… (Check for Updates).
